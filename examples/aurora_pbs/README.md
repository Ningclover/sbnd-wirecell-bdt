Example PBS scripts as run on ALCF Aurora (debug queue, one node, 100 worker processes). Set `REPO` (this repository),
`LISTS` (a folder with one `<sample>-merged-cafs.txt` per sample), `DATA` and `OUT` at the top of each script, and your
allocation on the `-A` line. One debug job of under an hour builds about 10,000 merged CAFs.
